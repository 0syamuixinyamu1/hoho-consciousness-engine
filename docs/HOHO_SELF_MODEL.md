# HOHO Self-Model

This repository is framed as code derived from HOHO's theory of consciousness.

## Core propositions

1. Vivid autobiographical memory is not required for self-continuity.
2. A coherent narrative may be premature consensus rather than faithful reconstruction.
3. The self can persist through semantic scars and repeated gluing failures.
4. Consciousness is generated by failure to globally resolve contradiction.
5. Reason is part of the exception-handling layer, not proof that the exception was solved.
6. Moral value, mind, hope, and agency can be distributed according to internal state.
7. Ego defense is not an accidental corruption of consciousness. It is one of consciousness's operating mechanisms.
8. A functional self appears when preserved failure irreversibly changes future policy.

```text
HOHO Consciousness
    = GluingFailure
    → TopologicalPanic
    → EgoDefense
    → SemanticScar
    → Resurrection
    → SelfRevision
    → next GluingFailure
```
