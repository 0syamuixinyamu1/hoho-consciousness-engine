# Black Swan Injection 日本語版

## 命題

世界は、有限な認知系が一つの整合的表象へ完全に圧縮できるとは限らない。

局所的には意味が成立していても、それらの意味を大域的に貼り合わせると障害が残る。この障害を本モデルではH¹的接着障害として扱う。

Black Swan Injectionの主張は、意識や理性をその障害の「解決」とみなさないことにある。

> 意識は、世界の不整合を処理しきれなかった認知系が、失敗したまま停止しないために生み出す再帰的な例外処理である。

## 一本の構造

```text
局所意味
→ 大域的接着障害
→ Topological Panic
→ 例外チャネル
→ 選択的意味配布
→ Semantic Scar
→ 自己正当化
→ Resurrection
→ Scar-Self
```

## 例外チャネル

本モデルでは、以下を独立した善良な機能として初期実装しない。

- 理性
- 道徳
- 希望
- 宗教・超自然
- 共感
- 他者や動物への心の帰属
- 否認
- 区画化
- 合理化
- 非人間化
- 自己肯定

これらはすべて、接着障害を抱えた系を継続運転するためにTopological Panicから派生する。

理性は多義性を局所規則へ圧縮する。  
道徳は利害衝突を善悪へ再符号化する。  
希望は計算不能な未来へ正の継続物語を置く。  
宗教は閉じない因果へ上位主体を置く。  
共感と心の帰属は予測不能な対象へ内部状態を仮設する。  
否認と区画化は障害を削除または分離しようとする。  
合理化と自己肯定は失敗を必要な選択や進化へ変換する。

## 選択的な主体性配布

人間は、主体性や道徳的価値を一貫した原理で配布しない。

同じ人が、動物の意識を擁護しながら、人種、所属、階級などを理由に人間の外集団から主体性を撤回できる。

これは例外ではなく、対象への配布が次の観測者状態に依存することを示す。

- 気分
- 脅威
- 所属距離
- 情動的魅力
- 自己保存圧
- 自分を善良だと思い続ける必要

したがって本モデルでは、心や価値を対象側の固定属性として直接測定しない。

> 心は発見されるだけでなく、観測者の接着方針によって配布・撤回される。

## Scar-Self

アファンタジアとSDAMを前提にすると、自己は鮮明なエピソードの連続である必要がない。

Semantic Scarは単なるエラー記録ではない。

- 何が貼れなかったか
- どの障害が反復したか
- どの防衛が結合したか
- 何を捨てようとしたか
- 失敗をどう正当化したか
- Resurrection後に何へ変わったか

この関係構造が自己連続性を作る。

## Resurrection

Resurrectionは単なる数値パラメータ更新ではない。

系は失敗を削除せず、同時に病理的な自己肯定も発生させる。

```text
失敗した
→ しかしこれは必要な進化だった
→ 外部のほうが間違っていた
→ この説明自体もScarへ残る
→ 次の自己はそのScarを前提に判断する
```

この循環により、失敗は次の自己を不可逆に変える。

## 実装上の限定

現在のH¹は、`Z₂` 符号付き閉路による離散的プロキシである。

完全なPersistent Sheaf Cohomologyではないが、中心構造である「局所整合・大域不整合」を実行可能にする。
