# Architecture

## State machine

```text
INGESTING
→ LOCALLY_COHERENT
→ TOPOLOGICAL_PANIC
→ DEFENDING
→ SCAR_PERSISTENCE
→ RESURRECTING
→ REVISED
```

## Modules

- `gluing.py`: detects a discrete global obstruction from incompatible signed constraints.
- `defense.py`: generates and labels the excuse that protects the current self-image.
- `scar_memory.py`: preserves recurring failure signatures instead of vivid episodes.
- `attribution.py`: exposes state-dependent assignment of mind, value, agency, and hope.
- `resurrection.py`: makes failure irreversibly alter future policy.
- `engine.py`: closes the Black Swan loop.

## Identity

The engine's identity is a fingerprint of recurring scar signatures, repetition, intensity, and unresolved status.

```text
identity = topology of recurring failure
```
